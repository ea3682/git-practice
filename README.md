I found the article interesting because AI is becoming a much nigger part of software development. It made me think about how the role of software engineers could change if AI is able to write most of the code. Developers may use less time writing the code and more time reviewing it, solving problems, making deign decisions and making sure it actually works. I also found it interesting since I am studying computer science during a time AI is improving quickly.I am curious about what the skills will be more important in the future and how to use AI without relying on it too much.
