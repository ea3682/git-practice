## Article

When AI writes Almost All Code, What Happens to Software Engineering? https://newsletter.pragmaticengineer.com/p/when-ai-writes-almost-all-code-what

## Why I Found It Interesting

I found the article interesting because AI is becoming a much bigger part of software development. It made me think about how the role of software engineers could change if AI is able to write most of the code. Developers may use less time writing the code and more time reviewing it, solving problems, making deign decisions and making sure it actually works. I also found it interesting since I am studying computer science during a time AI is improving quickly.I am curious about what the skills will be more important in the future and how to use AI without relying on it too much.

## Saudha Shaheen’s Thoughts (saudhashaheen,fs2761)

This article raises a question I find relevant while learning to code: **if AI writes more of the code, how do we make sure we still understand what we’re building?** The author describes generating code, then reviewing it and checking the tests before using it. I find that balance interesting because writing code faster would be useful, but I would still want to catch mistakes and know why the solution works. It makes me wonder how learning to program will change if reviewing code becomes as important as writing it.
